Инструкция по запуску:


1. Собираем java-проект, меняем путь к JAR в DockerFile при необходимости.
2. В терминале Docker desktop выполняем переход в папку с проектом: cd <путь к папке>. Запускаем кластер через команду терминала: docker compose up.


Создание топиков и настройка ACL реализованы в сервисе kafka-init.


FailConsumer - подписывается и пытается прочитать топик, на который нет прав.


SucConsumer - подписывается и читает топик, на который есть права.


Producer - отправляет данные в топики.

При успешном развертывании кластера в логах producer-app-1 будут сообщения об успешной отправке сообщений в kafka, в логах consumer-app-suc-1 будет выведено отправленное сообщение из первого топика, consumer-app-fail-1 упадет с ошибкой авторизации.
